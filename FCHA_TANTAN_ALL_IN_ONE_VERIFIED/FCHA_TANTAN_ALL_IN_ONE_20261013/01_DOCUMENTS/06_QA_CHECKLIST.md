| Case ID | 조작 | 기대 결과 |

| TC-06 | 관심 저장 3개 + 존재하지 않는 검색 | [개선] '조건에 맞는 관심 브랜드 없음' 표시 |
| TC-07 | 관심 해제 → 상세 → 돌아오기 | 해제된 브랜드가 관심 목록에 재등장하지 않음 |

| TC-09 | 지역 서울 → 제주 전환 | 지역 매장 수만 변경; 전국 매출은 변하지 않음 |
| TC-10 | API 숫자 필드를 null로 변경 | '미제공' 노출, 0으로 오해 불가 |
| TC-11 | 데이터 요청 실패 | 재시도 UI 노출 |

## 리스크 및 대응 우선순위

- **데이터 신뢰도(P0):** 실제 공공데이터가 들어가기 전까지 브랜드 및 성과값은 가상. 공개 서비스 지표로 사용 금지.
- **화면 오류(P0):** SCR-05 저장 0개와 필터 0개 메시지가 동일한 문제. 구현 수정 전 화면 QA에서 개선 필요로 표시.
- **전국/지역 수치(P0):** 지역별 매출이 없는 상태에서 전국 평균 월매출을 지역매출처럼 표시하지 않는다.
- **보안(P0):** 운영용 비밀키/허용 호스트/HTTPS 미설정 상태에서 공개 배포 금지.
- **검수 책임(P1):** 데이터 담당은 출처·통계 정의, 백엔드는 적재·API, 프런트는 표기 및 접근성을 각각 승인.
