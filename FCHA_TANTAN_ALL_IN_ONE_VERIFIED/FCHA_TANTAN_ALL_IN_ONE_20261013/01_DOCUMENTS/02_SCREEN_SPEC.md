# FCHA TANTAN | 통합 화면 설계서 v2.0

**작성일** 2026-10-13  | **근거** 첨부 `fcha_tantan.zip`의 `dist/js/app.js`, `dist/js/data-utils.js`, `backend/brands/models.py`, `backend/brands/views.py` | **범위** 공개 SCR-01~06, 관리자 SCR-07

> 이 문서는 실제 구현 확인 결과와 제안 사항을 분리한다. **[현행]**은 첨부 소스에서 확인한 동작, **[개선]**은 디자인·기능 목표이지만 아직 구현되지 않은 사항, **[검증필요]**는 실행 환경/실제 데이터 연동에 따라 확인해야 할 사항이다. 실제 고객 데이터가 아닌 8개 가상 브랜드 및 2024·2025년 예시 통계를 기반으로 설계한다.

## A. 공통 설계 규격

| 항목 | 규격 |
|---|---|
| 화면/라우팅 | SPA Hash route `#/`, `#/brand/:slug`, `#/compare`, `#/regions`, `#/saved`, `#/guide`; 관리자 `/admin/` |
| UI 방향 | 네이비 `#18243A`, 레몬 옐로우 `#F4EF76`, 화이트 `#FFFFFF`; 큰 제목·굵은 KPI·넉넉한 여백 |
| 기기 기준 | 데스크톱 1440px, 태블릿 768px, 모바일 390px; 비교표는 내부 가로 스크롤 허용 |
| 공통 헤더 | 프차 탄탄 로고, 브랜드 탐색, 지역 살펴보기, 브랜드 비교, 데이터 안내, 관심 브랜드 |
| 데이터 연도 | 2024년·2025년; 기본은 API 데이터의 `years[0]` (현재 2025). 상세·비교·지역·관심 화면 간 공유 |
| 대상 업종 | 카페, 치킨, 편의점, 미용실 |
| 데이터 스코프 | 매출/개업/폐업 = 전국 가맹점 기준. 선택 지역은 **매장 수에만** 적용 |
| 수치 표기 | 월평균 매출(만원) = `round(annual_sales_krw / 12 / 10000)`; 돈 원본은 KRW 원 |
| 결측값 | `null` = 미제공, `0` = 확인된 0. 비교/차트에 0으로 허위 치환하지 않음 |
| 가상 데이터 | `is_demo=true` 시 모든 중요 통계 화면에서 '예시 데이터' 명시 |
| 접근성 | 키보드 포커스, 이미지 대체 텍스트, 폼 레이블, 버튼 누름 상태, 44px 터치 영역 권장 |
| 사용자 상태 | 관심 브랜드 `localStorage['tantan-saved']`, 비교함 `localStorage['tantan-compare']`(최대 3개) |
| API | [현행] `GET /api/v1/brands/`, `GET /api/v1/brands/{slug}/` (읽기 전용) |

### 공통 레이아웃 영역

| 영역 ID | 구성 | 주의 사항 |
|---|---|---|
| L-01 | 헤더·글로벌 메뉴 | 모바일 가독성·키보드 접근 확인 |
| L-02 | 페이지 제목·설명·연도 | 여러 화면에서 동일 기준연도 반영 |

| L-04 | 비교함 플로팅 바 | [현행] 1~3개 선택 시 비교 화면 외에서 나타남 |
| L-05 | 출처·예시 데이터 표시 | 출처, 업데이트 날짜, 의사결정 주의 문구 |
| L-06 | 오류·빈 상태·로딩 | 목적에 맞는 다음 행동 제공 |

## SCR-01 | 브랜드 탐색 / 홈

| 분류 | 명세 |
|---|---|
| 경로·상태 | `#/` · [현행] 구현 |
| 사용자 목표 | 업종·지역·연도에 따라 브랜드 후보를 빠르게 찾고 비교·저장·상세 탐색 시작 |
| 주요 컴포넌트 | P01 헤더, P02 네이비 히어로·옐로우 CTA, P03 검색창, P04 업종 칩, P05 지역 선택, P06 연도 선택, P07 결과 수·정렬, P08 카드 그리드, P09 출처·주의 문구 |
| 초기값 | 업종=전체, 지역=전국, 검색어 없음, 정렬=매장 수 많은 순, 연도=API 최신 연도 |
| 카드 항목 | 사진(업종 참고), 브랜드/업종, 월평균 매출, 선택지역 매장 수, 전국 연간 개업·폐업, 하트, 비교 담기, 상세 |
| 이벤트 | 검색 입력 시 즉시 반영·Enter 제출, 업종 칩 클릭, 지역/연도/정렬 변경, 하트·비교·상세 링크 |
| 필터 | 브랜드명/업종 검색, 4업종, 17개 지역+전국. [현행] 특정 지역 선택 시 해당 지역 매장 수가 0 또는 미제공이면 목록 제외 |
| 정렬 | 매장 수↓, 매출↓, 개업↓, 폐업↑, 이름순. [현행] 프런트 `filterBrands`에서 처리 |
| 빈 상태 | 결과 0건 안내 + 필터 초기화 |
| 오류 | API/JSON 실패 시 재시도 버튼, 사진 누락 시 적절한 대체 이미지 [개선] |
| 완료 기준 | F-01~05 필터의 조합 정확, 2024/2025 수치 일치, 하트·비교 동기화, 반응형 점검 |

**상호작용 시퀀스** ① 최초 데이터 로드 → ② 검색/업종/지역/연도 선택 → ③ 결과 카운트·카드 갱신 → ④ 상세 혹은 관심/비교함으로 이동.

**정보 노출 원칙** 매장 수와 월매출은 서로 다른 통계 범위일 수 있으므로 카드에 `전국/선택 지역` 문구를 눈에 띄게 표시해야 한다.

## SCR-02 | 브랜드 상세

| 분류 | 명세 |
|---|---|
| 경로·상태 | `#/brand/:slug` · [현행] 구현 |
| 사용자 목표 | 단일 브랜드의 매장 규모·개폐업·지역 분포·비용을 살펴보고 다른 후보와 비교 |
| 입력 데이터 | `brand.id(slug)`, 전역 연도, `stats[]`, 지역 매장 수, 창업 비용 및 설명 |
| 화면 상단 | 탐색 경로, 목록 복귀, 연도, 비교 담기, 관심 하트, 브랜드명·영문명·소개·대표 참고 이미지 |
| KPI 영역 | 연말 전국 매장 수, 연간 개업 수, 연간 폐업 수, 평균 월 매출(만원) |
| 분석 영역 | 연도별 개폐업 막대그래프(선택 연도와 별개로 존재 연도를 모두 표시), 상위 지역 분포, 17개 지역 상세, 창업 비용 구성 |
| 액션 | 상세 목차 탭(페이지 내 스크롤), 하트 토글, 비교 토글, 뒤로 가기 |
| 예외 | 없는 slug: '브랜드를 찾을 수 없어요' + 목록 이동; 통계 누락 시 '미제공'; 이미지 실패 [개선] 기본 이미지 |
| 화면 주석 | 평균 월 매출은 순이익 아님; 창업비용에 임대보증금·권리금 등이 포함된다고 가정하지 않음 |
| 완료 기준 | 링크로 직접 접근, 2024↔2025 전환, 주석/출처 검증, 미존재 slug 처리 |

**주의** [현행] 개폐업 차트는 브랜드에 포함된 연도를 전체 표시한다. 문서나 화면에서 '3년 추이'라고 고정하지 않는다(현재 시연 연도 2개).

## SCR-03 | 브랜드 비교

| 분류 | 명세 |
|---|---|
| 경로·상태 | `#/compare` · [현행] 구현 |
| 사용자 목표 | 1~3개 후보를 동일 연도·동일 단위로 비교하고 CSV로 저장 |
| 구성 | 제목·연도·예시 레이블, 선택 건수, CSV 다운로드, 브랜드 추가, 비교표, 수치 정의 |
| 비교표 행 | 연말 매장 수, 연간 개업 수, 연간 폐업 수, 평균 월 매출, 예시 창업비용, 기준 면적, 17개 시·도별 매장 수 |
| 비교표 열 | 브랜드 1~3개. 헤더에서 브랜드별 제거 및 상세 이동 |
| 비교함 규칙 | `tantan-compare`에 slug 배열 저장. 4개째 추가 시 토스트, 현재 상태 유지 |
| 연도 규칙 | 하나의 연도 선택이 비교 대상 전체에 동일 적용 |
| CSV | BOM 포함 UTF-8, 연도와 데이터 구분 포함. 한 브랜드 한 행. [현행] 지역별 17개 수치는 CSV에 포함되지 않음 |
| 빈 상태 | 브랜드가 없으면 목록으로 이동하는 CTA |
| 개선 제안 | [개선] 기준연도별 증감률/전국 대비 상대 지표 추가 시 출처 정의 후 별도 기획 필요 |
| 완료 기준 | 0/1/2/3개 상태, 4개 차단, 개별 제거, 파일 헤더/데이터 정확성, 모바일 표 스크롤 검증 |

## SCR-04 | 지역 살펴보기

| 분류 | 명세 |
|---|---|
| 경로·상태 | `#/regions` · [현행] 구현 |
| 사용자 목표 | 17개 시·도 중 하나를 선택하여 등록 브랜드의 매장 분포 비교 |
| 구성 | 제목, 기준연도, 17개 지역 버튼, 지역 매장 합계, 브랜드별 순위표 |
| 기본값 | 서울 · API 최신 연도 |
| 표 컬럼 | 브랜드, 해당 지역 매장 수, 해당 브랜드 전국 매장 중 지역 비중, 비교 담기 |
| 계산식 | 지역 비중 = 해당 브랜드 지역 매장 수 / 해당 브랜드 전국 매장 수 ×100 (전국 값 0·null이면 미제공) |
| 범위 안내 | 등록된 **브랜드들만** 합산한 수치. 특정 지역 모든 프랜차이즈 점포 총수가 아님 |
| 이벤트 | 지역 타일 클릭 → 합계·표 갱신, 기준연도 변경, 브랜드 상세, 비교 담기 |
| 예외 | 지역 점포가 없는 브랜드 또는 전부 미제공이면 수치의 의미 설명 [개선] 결측 경고 강화 |
| 완료 기준 | 17개 타일, 선택 상태, 연도별 수치, 표 정렬, 출처 표기 확인 |

### 5-4. 데이터 및 계산 규칙

- 키 `tantan-saved` 예시: `["tantan", "may", "forest"]` (실제 프로젝트의 가상 브랜드 slug). 값은 JSON 문자열이며, slug 고유 식별자만 저장한다.
- 저장 목록 조회 과정: 앱 시작 시 JSON 파싱 → 문자열 배열이 아니면 `[]` → API에 없는 slug 제거(현재 앱에서는 `boot()`에서 메모리 목록만 정리) → 필터·정렬 적용 → 카드 렌더링.
- 표시된 카드의 `연말 매장 수`는 선택 지역 매장(전국 선택 시 전국 수치)이며, `연간 개업/폐업·평균 월 매출`은 **항상 전국 기준**이다.
- [현행] **현재 저장 목록 전체 개수와 결과 개수는 분리 표시되지 않는다.** [개선] 제목 옆에 총 저장 개수 배지를 두고, 결과 도구 모음에 필터 결과 개수를 별도로 표시한다.
- 평균 월 매출(만원) = `Math.round(annual_sales_krw / 12 / 10000)`; `null`일 때 '미제공'으로 표기.
- 저장 기능은 서버 API를 호출하지 않는다. 백엔드 `Bookmark` 테이블이나 `POST /bookmarks/`는 **미구현**이다.
