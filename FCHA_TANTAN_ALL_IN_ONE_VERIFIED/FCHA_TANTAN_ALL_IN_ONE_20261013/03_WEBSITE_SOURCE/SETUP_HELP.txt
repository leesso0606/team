RUN_SITE_WINDOWS.bat: Python 가상환경 생성 → 패키지 설치 → Django 마이그레이션 → 비어있는 DB에만 DEMO 입력 → http://127.0.0.1:8000 서버 실행
RUN_FRONTEND_WINDOWS.bat: Python 기본 내장 HTTP 서버에서 정적 데모 보기, http://127.0.0.1:8080
주의: 인터넷 연결이 필요한 첫 pip 설치. 배포용이 아니라 Windows 로컬 개발용입니다. 실행 전 압축을 모두 풀어주세요.
종료: 실행 콘솔에서 Ctrl+C. 관리자 계정은 자동으로 만들지 않습니다.
