8. 실제 브랜드 19개 등록하기

from django.db import transaction
from brands.models import Brand

with transaction.atomic():
    for brand in brands:
        Brand.objects.update_or_create(
            slug=brand['id'],
            defaults={
                'name': brand['name'],
                'category': brand['category'],
                'tagline': brand.get('tagline') or '',
                'english_name': brand.get('english_name') or '',
                'image': brand.get('image') or 'coffee.jpg',
                'is_demo': False,
            }
        )

코드 설명
- transaction.atomic() : 등록 도중 오류가 발생하면 이번 작업의 변경 사항을 되돌려 줘.
- for brand in brands : JSON에 있는 19개 브랜드를 하나씩 가져와.
- update_or_create() : 같은 slug가 있으면 수정하고, 없으면 새로 등록해.
- brand.get('tagline') or '' : 설명이 없으면 빈 문자열로 저장해.
- is_demo: False : 실제 브랜드 데이터임을 표시해.

10.실제 연도별 통계 48개 등록하기

AnnualStat 모델에 데이터를 저장

from django.db import transaction
from brands.models import Brand, AnnualStat

with transaction.atomic():
    for brand_data in brands:
        brand = Brand.objects.get(slug=brand_data['id'])

        for history in brand_data['history']:
            AnnualStat.objects.update_or_create(
                brand=brand,
                year=history['year'],
                defaults={
                    'stores': history.get('stores'),
                    'opened': history.get('opened'),
                    'closed': history.get('closed'),
                    'annual_sales_krw': history.get('annual_sales_krw'),
                    'source_label': '브랜드별 수집 데이터',
                    'source_url': '',
                }
            )

코드 설명
- Brand.objects.get() : 앞에서 등록한 실제 브랜드를 찾는 코드야.
- for history in brand_data['history'] : 해당 브랜드의 2024~2026년 데이터를 하나씩 가져와.
- AnnualStat.objects.update_or_create() : 브랜드와 연도가 같으면 수정하고, 없으면 새로 등록해.
- history.get() : JSON 값이 null이면 Python의 None으로 저장해.
- transaction.atomic() : 작업 중 오류가 발생하면 이번 저장 작업 전체를 되돌려 줘.
source_label은 우선 임시로 표시하는 값이야. 나중에 실제 출처 정보를 연결할 거야.

주의: JSON의 year와 source_accounting_year가 다를 수 있으므로, 현재는 JSON에 표시된 year를 기준으로 저장해. 원자료 기준 연도는 추후 출처 정리 시 별도로 확인
