# 디자인 수정 사항

- 메인: 네이비 배경, 선명한 옐로우, 큰 제목과 단일 버튼. 중복 소개 문구와 장식 카드 제거.
- 목록: 데스크톱 3열, 모바일 1열. 카드와 섹션 여백 확대. 검색·지역·연도·정렬 입력 기능 유지.
- 전체 화면: 본문 17px/500, 주요 제목 700. 보조 문구와 데이터 라벨 크기 확대.
- 업종: 카페·치킨·편의점·미용실 각 2개의 가상 브랜드.
- 연도: 2024·2025년, 기본 선택 2025년. 통계·지역·비교·CSV·Django 예시 입력 통일.
- 모든 통계와 비용은 시연용 가상 값입니다. 실제 자료를 새로 수집한 것이 아닙니다.
- 기존 데모 DB 사용 시 python manage.py seed_demo를 다시 실행하세요. 동일 데모 브랜드의 이전 연도 통계는 새 범위로 정리됩니다. 실데이터 덮어쓰기 방지는 유지됩니다.
