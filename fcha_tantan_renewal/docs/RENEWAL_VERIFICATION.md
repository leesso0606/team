# 리뉴얼 검증 기록

검증일: 2026-10-21

## 기능 검증
- Django 5.2.18 / Python 3.12에서 테스트 20개 통과.
- 회원가입·해시 비밀번호·로그인·POST 로그아웃·로그인 후 복귀·외부 리다이렉트 차단·CSRF 확인.
- 회원별 관심 브랜드 격리, 비회원 상세/지역/CSV/API 접근 차단 확인.
- 비교 브랜드 최대 2개 및 오래된 3개 선택 세션 정리 확인.
- 회수 계산: 투자 10,000만원 / 월매출 2,000만원 / 고정비 800만원 / 변동비율 40% → 월 순이익 400만원 / 회수 25개월 / 월 BEP 표시 1,333만원 (내부 계산 약 1,333.33만원).
- 적자·이익 0·변동비 100%·음수·NaN·잘못된 브랜드·평당 매출 null/0·가져오기 전체 롤백 확인.
- 선택 비용 2개를 생략하거나 빈 문자열로 제출해도 0으로 계산. 6개 입력의 step=1 및 소수 입력 거절, 내부 소수 계산과 정수 결과 표시, 로그인 닉네임 및 GNB 확인.
- 이번 사용성 수정에서는 DB 변경과 신규 migration이 없습니다. 직전 전달본과 DB 파일 바이트를 대조했습니다.
- makemigrations --check --dry-run: 변경 없음. check: 이상 없음. prepare_db.py: 정상.

## 화면 검증
- Django 서버 렌더링 결과를 임시 정적 프리뷰로 열어 브라우저 검증. 실행 환경의 프리뷰 서버는 Python 런타임을 지원하지 않아 실제 HTTP Django 서버 대신 이 방법을 사용했습니다. 서버 기능은 Django Test Client로 검증했습니다.
- 데스크톱: GNB 중심=콘텐츠 뷰포트 중심. 우측 메뉴 펼침, 기본/상세/회원가입 화면 시각 확인.
- 그래프: 3번째 항목 선택 차단, 해제 후 새 항목 선택 시 두 그래프 갱신, 스크롤 후 sticky top=108px 확인.
- 390px iframe(스크롤바 제외 콘텐츠 375px): 메인/계산기 화면 폭 넘침 없음. 카드 2열.
- 320px iframe(스크롤바 제외 콘텐츠 305px): 비교 페이지 scrollWidth=clientWidth=305px. 비교 표 폭과 scrollWidth 모두 271px. 두 브랜드 열이 가로 스크롤 없이 표시되며 긴 이름/항목은 줄바꿈합니다.
- 비교 체크박스 16×16px, SVG 12×12px의 가로·세로 중심 차이 모두 0px. 닉네임 상단 표시·정수 입력 ArrowUp(10000→10001) 확인.
- 필터 제출 전후 scrollY=137px 유지 확인. 임시 프리뷰의 정적 HTML에서는 실제 필터 결과 대신 이동/복원 동작을 검증했습니다.
- 카드의 상세 링크 오버레이 inset=0px 확인. 지역 전체 목록 summary에 pointer 커서 적용.
- 선택한 TT 로고·검색 패널·밝은 블루 배너와 카드 레이아웃 반영.
