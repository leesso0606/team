# 리뉴얼 변경 안내

## 화면·소스
- `static/css/renewal.css`: 블루 테마, 4/3/2열 반응형 카드, 중앙 GNB, 회원 메뉴, 그래프 고정.
- `static/js/common.js`: 필터·정렬·동일 페이지 폼 제출 시 스크롤 복원과 햄버거 인터랙션. `static/js/compare.js`: 최대 2항목 비교 막대그래프.
- `accounts/`: 표준 Django 회원 기능과 회원별 관심 브랜드. 별도 인증 라이브러리/외부 계정 연동 없음.
- `brands/calculator.py`: 입력 검증·서버 계산. `brands/test_renewal.py`: 기능·보안·산식 검증.
- `static/images/brand-symbol.svg`: 채택 TT 로고를 웹용 SVG로 구성. 글자는 실제 HTML 텍스트.
- `static/images/hero-blue.png`: 선택한 3안 배너 방향의 생성 이미지. 헤드라인·버튼은 실제 HTML.
- 기존 템플릿 변수, 브랜드 slug, 데이터 파일, 원본 이미지와 수집 스크립트는 유지.

## DB
실행 전 `python scripts/prepare_db.py`. 기존 테이블은 그대로 두고 2개 테이블만 추가합니다.
기존 브랜드 자료를 새 가상 값으로 재생성하지 않습니다. `seed_demo`는 기존 학습 명령으로만 남겨 두었으며 시작 스크립트에서 호출하지 않습니다.

## 평당 매출 자료 검토
현재 실제 브랜드와 가상 브랜드의 연결이 없어 공시 평당 매출은 미제공입니다. XLSX의 상·하한은 평균이 아니며 배율과 기간 확인 전 임의 연환산하지 않습니다. 원시값과 셀 위치를 review JSON으로 남겼습니다. 검증 완료된 값만 AreaSales에 연결할 수 있습니다.

## 웹 API 권한 변경
- 비회원 GET `/api/v1/brands/`: 기본 목록/통계 요약, 비용·면적·지역 상세 제외.
- 회원 GET `/api/v1/brands/`: 상세 필드 포함.
- 비회원 GET `/api/v1/brands/<slug>/`: 401 JSON 응답.
- 회원 상세: 기존 키 보존 + `annual_sales_per_pyeong_krw`, `area_source_label` 추가.
- POST 변경 작업은 기존대로 CSRF 보호. CSV와 상세 페이지는 회원만 접근.

## 추가 사용성 수정
- 계산기의 기타 고정비·변동비율 선택 입력(빈 값 0), 모든 입력 정수/step=1, 결과 금액 정수 반올림. 내부 계산은 Decimal 정밀도를 유지합니다.
- 지원 정보 GNB를 회수 계산기로 교체하고 로그인 닉네임을 상단에 표시합니다.
- 카드 전체 상세 링크, 별도 비교/관심 버튼, 지역 목록 포인터, 체크박스 SVG 정렬, 전반적인 글자 확대.
- 모바일 비교 표는 고정 레이아웃과 줄바꿈으로 320px 화면에서도 두 브랜드를 함께 표시합니다.
- 코드만 수정하며 기존 회원·관심 브랜드가 저장된 로컬 db.sqlite3는 그대로 사용하세요.
